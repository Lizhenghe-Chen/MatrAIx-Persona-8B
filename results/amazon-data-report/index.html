01

数据源是什么

官方定义（ProductSpec）

Amazon Review —— “按时间排序的评论历史”。由 Qwen3.6 medium_b 提取并经过 schema sanitizer 清洗，翻译到 1,290 字段契约。原始 100,000 条，经质量过滤与 MinHash 去重后 97,915 条全部保留 进入 1M coreset（官方规则：All retained rows，不抽样）。

记录级证据（metadata）

每行 parquet 自带 metadata_json，本报告全量读取了全部 97,915 行——这是真实消费者行为痕迹，而非问卷或百科文本：

· user_id — Amazon 用户 ID
· review_count — 该用户评论条数（中位 44、最多 720）
· user_bucket — 用户分桶
· prompt_variant: medium_b — 提取配置

画像洞察（全量证据）

真实活跃评论者
评论量中位 44 条、均值 53.5、最多 720 条——这不是问卷受访者，而是持续写评论的 Amazon 用户。
信任评论生态
在线评论态度 97.6% 积极（35,062/35,928），仅 1.8% 怀疑——天然适合评价采纳、口碑传播类场景。
价值驱动 + 成本敏感
经济动机 92.5% 价值驱动、另有 7.4% 成本敏感；消费储蓄 99.9% 平衡或节俭——性价比是主线。
分析型 + 核验型
决策风格 98.3% 分析型；信任级别 80.8% 核验中（17,939）——会查证、会对比的谨慎消费者。
口语化、移动端
语域 98.6% 口语（10,675）；设备上下文移动 63.4%（6,324）——用生活语言、在路上提问。
认知：具体、细节、少提问
抽象度 98.9% 具体或非常具体；细节导向高；提问频率 89.3% 很少提问——要直接可操作的答案。
AI 态度：中立为主
att_ai 覆盖 5.8%，其中 70.1% 中立、24.1% 积极——对 AI 不狂热也不排斥，适合做中立基线人群。
人口学：稀疏、偏年长且偏北美
年龄/性别/区域覆盖率均 <12%；已标注样本 72.9% 女性、98.5% 北美；年龄偏年长——55+ 占已标注的 61.8%（55–64 岁 2,649、65+ 1,130）——抽样时需按需补充分层。

在 MatrAIx 中使用 Amazon 人群

直接调用 1M 中的全部 amazon

# 1M 池 · 仅 amazon 来源 · 随机抽 100 人 · 生成 Job Recipe YAML
uv run python application/scripts/generate_application_job.py \
  --task application/tasks/example-survey_product-feedback \
  --execution-mode auto \
  --dataset persona/datasets/matraix-persona-1m \
  --sources amazon --sample-size 100 --seed 42

也可在 Playground 人群配置区：数据集切换为 matraix-persona-1m，来源筛选只勾 Amazon。注意：amazon 人口统计覆盖稀疏且偏北美/女性/年长，做均衡样本时建议叠加 --stratify dimensions.age_bracket 或维度过滤补充分层。

数据口径：分析对象为本地 matraix-persona-1m/release（persona-1m-0003/0004 分片）中全部 97,915 行 source: amazon；属性按 persona_codes.schema.json（nibble 低位优先 + null_bitmap 反相 + code 直索引）解码，并应用 attribute_overrides（1,130 条 age_bracket 修正为 65+，原始编码误标 Under 5）；中文标签取自 dimensions.labels.zh-Hans.json；来源规模取自 release/manifest.json / audit.json / README（Amazon Reviews 2023，McAuley Lab）并经逐行复算。覆盖率 = 该维度有值人数 / 97,915。解码正确性三重官方验证：① 与官方 _unpack_nibbles / decode_persona_1m.py 逐位一致；② validation-subset 权威真值 persona_0001 全 96 维度匹配、0 差异；③ 官方预解码 sample.parquet 97 个 amazon 行 2,005 个非空单元格 100% 匹配。官方明示"human-grounded ≠ verified"（模型提取可含噪声）且真实源保留自身分布、不具人群代表性。生成时间：2026-09-17。图表由 ECharts 渲染，数据为一次性本地快照。
