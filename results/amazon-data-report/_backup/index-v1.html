数据源是什么

官方定义（ProductSpec）

Amazon Review —— “按时间排序的评论历史”（chronological review histories）。由 Qwen3.6 medium_b 提取并经过 schema sanitizer 清洗，翻译到 1,290 字段契约；规模 100,000 条、全量保留，最终由 256 个 bucket 组装（167 续写 + 89 源桶）。

数据性质与溯源

与 GSS（调查问卷）、Wiki（百科人物）、StackOverflow（开发者调查）不同，Amazon 源是真实世界的消费者行为痕迹——商品评论历史。本池 29 人全部带 provenance：父池 matraix-persona-1m、HF 仓库 MatrAIx2026/MatrAIx_Persona_1M_Public_Release、原始 ID 前缀 amazon-*。

05

画像洞察

评论者：在线评论 100% 积极
覆盖 18/29 人，全部持积极态度（Positive）——天然适合电商评价、评论采纳类场景模拟。
决策：分析型 + 核验型信任
decision_style 全为 Analytical；trust_level 以 Verifying（核验中）为主——会查证、会对比的谨慎消费者。
动机：价值驱动 + 节俭倾向
economic_motivation 全为 Value-driven；消费储蓄偏 Balanced / Frugal saver——价格敏感、看重性价比。
技术：熟练但新事物谨慎
tech_savviness 全为 Comfortable；att_new_technology 积极为主、少量 Skeptical——会用但不盲从。
时间：不赶时间、问题简单
time_pressure 多为 No rush；query_complexity 以 Simple factual 为主——从容、直接的具体问题。
认知：具体、细节、低提问
cog_abstraction 偏 Concrete、细节导向 High、提问频率 Rarely asks——表达直接、看重可操作信息。
生活：健康事件与照护角色
major_life_events 以 Health journey 为主；照护者身份（老人/儿童）各 3 人——健康与家庭场景覆盖。
人口学：稀疏但真实
region 以北美为主，偶见年龄/性别/城乡——文本提取的自然后果，不构成均衡样本，抽样时需自行分层。

在 MatrAIx 中只使用 Amazon 人群

CLI 一行命令

# 仅 amazon 来源 · 随机抽 10 人 · 生成 Job Recipe YAML
uv run python application/scripts/generate_application_job.py \
  --task application/tasks/example-survey_product-feedback \
  --execution-mode auto \
  --sources amazon --sample-size 10 --seed 42

也可写入任务级 persona_strategy.json 的 "sources": ["amazon"]，或在 Playground 来源筛选（Sources chips）中只勾选 Amazon。想用更大规模的 Amazon 人群，导入官方 Persona 1M 后加 --dataset persona/datasets/matraix-persona-1m。

数据口径：分析对象为 matraix-persona-dev-sample（200 个 persona）中 29 个 source: amazon persona；维度中文标签取自 persona/schema/labels/dimensions.labels.zh-Hans.json；原始数据定义取自 profile_datasets.py 的 ProductSpec。覆盖率 = 该维度出现人数 / 29。生成时间：2026-09-17。图表由 ECharts 渲染，数据为一次性本地快照。
