## 冻结和运行

- 种子 20261109。每个研究 4 位技术测试、96 位正式评估，余下作为训练或试答来源。按固定从合格受访者中抽取且不重复使用画像，两组共享画像和题序。使用公开 Persona 1M 已允许的类别字段，按地区、年龄、教育、性别匹配。瑞典使用发行版的西欧大区范围。就业、家庭规模来自画像自身。排除来源为真实问卷、GSS 和 Amazon 的画像，不向 API 发送受访者编号、个体答案、权重、联系资料或自由文本。
- 原生单选及原生指令加概率分别调用。对同一概率取最大项是离线诊断。两个端点分别检查格式。Pro 峰值成本估算用官方无缓存价 1.32 USD／百万输入 token、3.96 USD／百万输出 token，采用字节数加消息封装余量和输出上限保守估算。首轮最多 400 次请求，尝试及重试总计最多 440 次、10 USD。每个可恢复错误最多重试一次。身份变化停止，未知传输状态不重复发送。
- 每卡至少 20 位评估者才用于群体比例评分。食品问卷的 20 位试答者从独立余样固定随机抽一次，比较直接统计、各半混等概率、各半混 AI。另抽 199 次，每次 20 人，描述试答抽样敏感性。瑞典题卡轮转，以整位受访者为预算时 20 位试答者不足以覆盖每张卡，省略该项。
- 瑞典商品模型以训练侧选择拟合带正则化的多项模型，解释变量是原商品属性、位置、价格与拒买常数。个人更新以固定幅度改变一个系数，按本人两次实际选择对这些候选偏好重新加权。错配在相同粗年龄组内轮换整块已知选择。只调拒买作诊断。同信息模型需要传入本人的两次选择，瑞典微观记录保留本机，使用统计三组完成该部分。

## 判卷

以受访者为抽样单位做 2,000 次配对重抽样。食品标签在公开抽样层内重抽并应用饮食访谈权重，区间衡量本次试验抽样波动。群体误差按合格题卡等权，同一人重复看到同一张卡时先在人卡内平均。个人概率误差按实际选择任务先在人内平均。按预定指标分别采用至少 2 个百分点、相对 2% 的门槛，并要求改善的 95% 区间全高于零。固定试答对照的区间以固定试答集和固定 AI 先验为条件。

瑞典报告三项分数：完整的三选一误差、拒买概率误差、在真人实际选购时的商品选择误差。当单选结果把两款产品概率都设为零时，条件误差计算原流程在这两款间没有给出区分，使用二者等概率并单独记数。使用训练侧真实答案的方案作为不同信息条件的成绩并列展示。

## 复算

私有工作区 `~/.local/share/matraix-decision-transfer/work/final-v1` 保存冻结文件、逐人材料和调用日志。只凭 Git 可重新生成 HTML 和检查聚合文件哈希。复算逐人结果需要原件及冻结日志。

```sh
.venv/bin/python examples/decision-transfer/src/final_score.py
.venv/bin/python examples/decision-transfer/src/build_final.py
.venv/bin/python examples/decision-transfer/src/build_final.py --check
```
