# 下一阶段方案草案：用可复用的真人信息预测未见选择

日期：2026-11-13。状态：准备草案，尚未预注册冻结；尚无新效果分数。

## 1. 用一句话说目标

不是每次先拿到新问卷的答案，而是先了解人，再预测这个人面对新商品时的选择。

本阶段首先筛查：真实、可复用且不含目标题答案的信息，是否有额外预测价值；这种价值是否依赖信息属于对应的人。若没有价值，不继续投入跨领域全量测试。

## 2. 哪些信息可以用

- 基础资料：真实年龄、学历等有明确口径的字段。
- 候选额外事实：原研究实测、时点允许、与决策有关的需求、约束或偏好。具体字段必须通过原题与代码本核验，不事先规定一定有预算或家庭设备字段。
- 商品与情境：原题实际展示的商品属性、价格、货币、用途、时间和信息条件。
- **不能用**：本题答案、答案派生分数、同一目标研究的答案比例、选择后的解释、模型编写的个人经历。不能把收入换算成预算，也不能把一般价值观直接改名为购买约束。

真人资料只用于它实际对应的人。合成人格另行标注，不能把不同研究中背景相似的人拼成一个“真人”。

## 3. 首轮只做信息增量筛查

固定DeepSeek Pro（预期ID `deepseek-v4-pro`）、非思考、温度0.7、top_p=1、完整选项概率。实际端点身份在技术试跑核验；不静默替换。先不微调、不搜索提示词、不添加本人已知选择示例、不混合同题真人比例。

三组共用同一批人、同样题面、选项顺序和简短预测指令：

| 条件 | 模型看到什么 | 要回答什么 |
|---|---|---|
| 只有基础信息 | 同一人的基础背景与商品情境 | 新阶段简化参照 |
| 加本人真实资料 | 基础信息＋经过核验的本人额外事实 | 额外信息能否帮助预测？ |
| 加可比他人的资料 | 基础信息＋合法供体的完整额外事实块 | 是否真的需要对应到本人？ |

三组使用相同字段集合和缺失表达，不按效果为研究挑字段。供体须属于同一研究及可比人群、不是本人、不产生明确事实冲突；合法供体不足时报告，不能随意放宽。

这是“真实信息是否有增量”的筛查，**不是完整原版MatrAIx与新系统的整体排名**。核心筛查不先堆入合成性格，以免把真实信息与虚构设定混淆。若通过，再研究如何把这些可复用事实接入MatrAIx，并单独检验合成人格是否还有增益。

两套研究各不超过48人作为首轮规模目标；各研究至多额外4人格式试跑。每人保留原分配中可完整还原的必要题组，不统一硬裁成四题。若每人可以一份请求完成，筛查共288份请求，试跑24份；这只是条件估计，最终以分块与token预算为准。当前没有运行授权，不创建付费任务。

## 4. 如何检验换商品之后还能用

先只在开发研究确定一个候选方法，再冻结字段处理、提示和评分。

- 新组合：同品类中未参与方法开发的商品组合。
- 新品类：整个品类不参与方法选择；真实资料的获取不能依赖这个品类的目标题答案。
- 新地区：单列后续验证，不因另一国家成功就自动通过。

初轮不把这三层一口气铺开。先确认“本人额外资料”比基础资料及错配资料更好，再做新品类复验。通过只说明可用的信息确有预测价值，不证明人格的因果作用。

同一个人的所有记录尽量放在同一数据集合，避免靠记住这个人的其他评估记录取得虚假迁移。若研究专门检验“同一人跨品类”，须另列这一设定，与“新人＋新品类”分开。

旧15套的成绩已经被查看。旧数据上的新划分只能作为探索或内部留出，不能称全新独立验证。新研究是否独立由来源、面板、人员重叠和历史使用记录判断，不由文件夹名称判断。

若字段审查发现两套都只有泛泛的人口/态度信息，就先报告“现有数据不能检验这个改法”；届时再由用户决定是否补充一份短的真实资料采集，而不是硬跑一次注定答非所问的实验。

## 6. 判断标准

主指标：个人选择的概率误差（Brier，越低越好）。每个人先平均自己的题目，再研究内汇总；按人配对重抽样2,000次，保留原研究分层和适用权重。

- 相对“只有基础信息”误差下降至少2%，并比较95%区间。
- 本人资料应优于错配资料；区间跨零只能称线索，不能声称已了解对应的人。
- 原设计支持时另报群体比例、分群差异、拒买和属性取舍。每卡人少时不把一两人答案解释成群体分布；“20人”也不是自动准确的保证。
- 同信息参照包括各选项等概率和无个人资料的可用参照；若训练统计模型，必须说明使用了哪些研究的真人答案。目标研究答案参照可做本地诊断，但不得进入冷启动主方法或伪称相同信息条件。
- 有效完成率至少98%；失败不补默认答案。费用、调用数和规则在运行前冻结。

“70+分”不是统计指标或验收数字。只有在没有目标答案辅助的未见任务上形成稳定、可复现的改善，才有理由提高主观可信度评价。首轮小样本不承诺证明广泛适用。
