# 把极端概率往均分拉，什么时候会更接近真人？

用已有内网 Qwen 的完整概率重放，不新增调用。问题是新问卷还没有真人答案时，能否靠一个固定规则降低误差。对每道题保留模型原概率的 75%，剩下 25% 按选项均分。例如三选一的 90%、5%、5% 会变成约 75.8%、12.1%、12.1%。另一条规则只调整各商品之间的比例，保留「都不买」的原概率。校准研究支持用留出数据检查概率，跨数据迁移需要另行验证。 [概率校准研究](https://proceedings.mlr.press/v70/guo17a) · [分布变化与校准](https://proceedings.neurips.cc/paper/2019/hash/8558cb408c1d76621371888657d2eb1d-Abstract.html)

九个对照组来自五个研究来源组。同一 RADIANT 发布里的西班牙番茄、意大利奶酪和苏格兰酥饼归为同一来源组。美加烘干机归为一组，两种牛排付款条件归为一组。另比较仅用其他来源组拟合一个通用收缩幅度。拟合按来源组等权，预测目标组时排除该组全部答案。牛排两组只用于检验，未用于拟合任何一套。25% 是这次探索设置。所有数据此前均被用于开发或探索。

Brier 越低越好。全选项收缩在六组降低误差，五组按卡重抽样的改善区间高于零。全选项收缩在美国啤酒仍输给均分。收缩在德国番茄包装和牛排两组的误差点估计升高，按卡区间均跨零。按答题量加权的逐卡分布误差在美国啤酒从 25.48 降到 21.39 个百分点，西班牙番茄从 24.21 降到 23.30，苏格兰酥饼从 29.09 升到 30.07。这说明即使整题概率误差改善，各张卡的真人选项比例仍可能更难还原。

按人和按卡分别重抽样 2,000 次。按卡时啤酒同一选择卡的不同说明一起重抽。区间条件于固定模型调用及拟合参数。其他来源拟合出的收缩幅度在 24% 至 47% 之间，也未修复德国包装题或牛排的退化。只调整商品也未跨组复现。当前可保留原概率、均分和固定收缩做并列诊断。已有证据不足以设成默认调整，或据此投入 DeepSeek Pro。 [牛排题面与付款条件](实际付款条件与拒买预测.md)
