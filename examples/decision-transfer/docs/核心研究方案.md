# 核心研究方案：真实资料能否帮助 AI 预测对应的人

版本：v1；固定日期：2026-11-13。用户已批准方向与实施流程；数据尚未准入，正式输入及付费预算尚未核定。本文件固定设计，不代表已有实验结果。

## 一句话目标

不提前知道新问卷的答案，利用一个人已有的真实测量资料预测商品选择。不是每换商品就先调查同题答案，也不是证明完全没有真人信息的合成人群已可靠。

收入不能自动变成预算，文化态度不能改名为购买约束，合成人格不能写成对应真人的事实。“70分”只是期望，不是统计验收指标。

## 四组比较

| 名称 | 输入 | 目的 |
|---|---|---|
| 当前 MatrAIx 方案 | 按冻结规则匹配的合成人格 | 是否超过当前已采用的方法 |
| 只有真实基础资料 | 本人核验过的人口资料 | 简化参照 |
| 增加本人真实资料 | 相同基础资料＋本人实测附加资料 | 唯一优化候选 |
| 换成他人的资料 | 相同基础资料＋可比他人完整附加资料块 | 是否真的需要对应本人 |

当前方法固定为 DeepSeek Pro、原生问卷指令、完整选项概率和匹配画像，不添加同题真人比例。四组同人、同题、同顺序、同分块、同模型参数、同任务指令；三个真实资料组使用相同格式。当前方法保留原生人格渲染，因此其比较是整体方法比较；资料贡献由其余三组解释。

非思考模式、温度0.7、top_p=1；关闭检索和工具。输出长度按完整题组在技术检查中确定后冻结。没有微调、提示词搜索、本人已知选择示例或真人答案混合。

## 两种模型分工

内网 Qwen/Qwen3.8-27B（http://10.120.47.101:8000/v1/chat/completions）负责低成本流程检查。正式成绩仅用 DeepSeek Pro，预期标识 deepseek-v4-pro；不静默换模型。Qwen 的成绩不用于筛掉研究或挑提示，不与 Pro 成绩混算。Pro 单独做接口及输出核验。

## 数据及逐步推进

先审查美国商品产地和瑞士六品类电子产品。前者核对第一波文化态度；后者核对环保等资料的题意、来源、测量时点及是否由答案计算。瑞士服装、食品人员提前留出，首轮通过再测试。

两套任一套不能完整还原任务或没有合格附加资料，先报告缺口，不自动替换研究或补造字段。一个有来源、有信息量的字段即可，不为凑数量加资料。缺失写未知；选择后态度、解释及答案派生指标不进入输入。后测的稳定人口资料须注明假设。瑞士旧映射将环境影响误作当地经济影响，在新目录按作者材料修正，旧证据不改。

每套48名评估人员，另4名技术人员，种子20261109，按研究原有分层比例抽取。匹配及供体不能接触答案；报告匹配覆盖、偏差、重复画像和排除人群。

Qwen：32次技术请求＋16次重复，共48次，含修复重试上限96。Pro：同样48次技术请求＋384次评估，共432次；最多44次失败重试，总上限476，每个失败请求最多重试一次。以上假设一人完整题组一份请求；需要分块时先重新核定，不删必要题目。建议Pro费用上限10美元，实际输入及官方价格核算后提交确认，不自动超支。

只有首轮通过，才进入提前留出的瑞士服装48人、食品48人，保持方法不变，另核预算。没有通过则结束，不扩样刷分。

## 怎样判断提升

主指标为选择概率误差（Brier，越低越好）：自信却选错会受到较大惩罚。先平均每个人的题，再按原设计及适用权重在研究内汇总。按人分层配对重抽样2000次，给95%区间；两套分别报告。

依次比较本人资料与当前MatrAIx、基础资料、他人资料。辅助报告答对率、拒买、少数选择、可支持的分群及群体比例；加入各选项等概率参照。稀疏选择卡不用于宣称群体比例准确。技术重复不是新增真人。

两套研究都满足：相对当前MatrAIx误差下降至少2%，优于基础资料、他人资料和等概率参照，才建议新品类复验。点估计通过但区间跨零只能称值得复验的线索；明确支持某项改善还要求其95%区间完全高于零。

这不是保证永久不过拟合。旧研究仍属探索或复验；瑞士多品类是同一研究，不是多项独立证据。换品类且换人不能解释为同一个人跨品类一致。错配诊断不证明人格因果作用。本阶段不训练模型，只检验输入方法能否复用。
