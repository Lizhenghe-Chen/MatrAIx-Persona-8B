# 冻结不是认可旧报告中每一句解释

本阶段保留旧文件的原样内容，保证可追溯，不把它们当作不能质疑的事实。

1. 旧`cluster-summary.json`把SHED的`cluster`标成`Pew`。SHED来自美联储，不能仅凭旧标签就归入Pew面板。本阶段不会沿用这一分簇；独立性重新核对。旧文件未改。
2. “已有真人答案训练的统计参照”与“只看画像、没有同题答案的AI”信息条件并不相同。只有后来给AI相同历史比例的对照，才更接近该层面的信息对等。新报告必须注明这一点。
3. 旧资料中“信息是原因、措辞不是原因”等说法，不自动升级为排除了所有其他机制。未测量的决策约束、任务重建、抽样和输出偏差仍需区分。
4. 35分、55分是上一阶段的主观评议，不是测量值；本阶段不以提高该数字作为优化目标。
5. 新阶段复制的4份汇总仅用于认识已有证据与限制，不作为新训练输入，不混入新效果成绩。
