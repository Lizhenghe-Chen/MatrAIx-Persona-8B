# 加一句「有机标准相同」，AI 能预测顾客会怎么变吗？

**这轮仍是「先预测不变」更接近真人。** 把两个情境放在同一个请求中比较，比各问各的更准，但距离真人观察到的变化仍有差距。

## 真人和模型看到了什么

台湾甜椒问卷里，526 名完成六题的受访者未收到额外说明，361 名收到说明。说明告诉受访者，在台湾销售的有机食品无论产自哪里，都适用相同的法规和管理程序。本轮按作者原图的含义转写成繁体中文，沿用上轮的 36 张卡、商品位置和预算提醒。模型请求只有题面，不含真人选择或背景。[原问卷和逐人数据](https://pmc.ncbi.nlm.nih.gov/articles/PMC5996284/)

用同一内网 Qwen 版本比较三种办法。第一种假定说明不会改变选择。第二种把两个情境分别交给模型，每张卡独立请求两次。第三种在同一请求中展示两个情境，明确要求比较并给出两套完整概率。另复算只保留模型所预测变化的四分之一。联合比较同时改变了指令和呈现方式，且在分开请求的首批完成后补跑。共 108 次有效请求。

## 哪个办法更接近真人

先按原卡算有说明与无说明两组的选项份额差，再将模型差值与其比较。对每张卡将四个选项的绝对误差相加后除以二，最后在 36 张卡上等权平均。

| 预测方法 | 变化误差（百分点，越低越好） |
|---|---:|
| 假定选择比例不变 | **9.10** |
| Qwen 分开预测两个情境 | 23.03 |
| Qwen 同时看两个情境 | 16.22 |
| 分开预测，只保留四分之一的变化 | 10.86 |
| 同时预测，只保留四分之一的变化 | 9.91 |

同一张卡、同一份无说明请求，两次输出平均相差 19.14 个百分点。分开问两个情境得到的平均差异为 20.06 个百分点，两者很接近。这个重复对照每卡只有两次结果，可以说明单次预测很容易受调用波动影响，尚不能量化稳定的真实说明效应。

真人「都不买」的比例增加 0.93 个百分点，按受访者在组别与原分配题组内重抽样 2,000 次，95% 区间为 −1.58 至 +3.51。Qwen 分开预测为下降 2.31 个百分点，一起问为下降 1.53。中国有机甜椒的选择率在人群中下降 1.07 个百分点，区间为 −2.96 至 +0.86。两种问法预测上升 2.42 和 1.14 个百分点。真人差值存在不确定性。汇总保留重抽样时固定卡片及模型输出后的误差对比。

原论文另对 800 人做了倾向匹配并估计属性作用。本轮使用完整答题者的原始份额差，回答的是实际题卡上的总体比例怎么变，两种估计口径不同。当前也无法排除公开问卷或研究结论出现在模型训练中。[原效果论文](https://doi.org/10.1016/j.foodqual.2017.12.004)

**可复用的验收办法**是先加一条「条件改变后比例不变」的参照，再用原样重复的请求测模型波动。这轮联合呈现和缩小预测变化仍未达到 DeepSeek Pro 复验条件。
