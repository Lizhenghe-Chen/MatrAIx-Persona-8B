# 烘干机涨价后，AI 的预测更接近真人了吗？

**纠正涨价方向能挽救一种表现较差的预测方法，但这次没有证据表明它比直接问 Qwen 更接近真人。** 简单的价格规则已经能给出接近的结果，因此先保留它作为对照。

## 比较了什么

使用 Ceolotto 和 Denny 的四国烘干机问卷中美国和加拿大的部分。真人在两款烘干机和「都不买」之间选一项。美加是同一研究中的两个地区。这些是问卷选择，论文研究了能效信息呈现方式对选择的影响。[原论文及实验设计](https://link.springer.com/article/10.1007/s10603-023-09556-5)

从已复用的研究材料中固定随机抽出美加各 16 张商品卡，每张卡的两款原始价格都不同于本地区参考价。所选卡覆盖美国 208 人、加拿大 214 人。每张卡保留商品和能效信息，另生成三张用于询问 Qwen 的卡：两款都用参考价、只给第一款涨 200、只给第二款涨 200。美国参考价 900 美元，加拿大参考价 1,000 加元。共新增 96 次调用，全部有效。沿用同一模型指纹的旧调用作为直接预测。所有评分使用真人实际看到的原价卡。

## 和真人差多少

分布误差单位是百分点。每张卡先算三项选择比例差的绝对值之和，再除以二，最后对卡片等权平均。越低越好。

| 方法 | 美国 | 加拿大 |
|---|---:|---:|
| 直接问 Qwen，用原价和完整商品信息 | 24.24 | 22.50 |
| 只问同价卡，忽略回到原价时的变化 | 38.20 | 31.33 |
| 用 Qwen 估出的价格响应，推回原价 | 41.72 | 42.63 |
| 同上，但将反向的价格响应归零 | 34.77 | 28.17 |
| 同价卡由 Qwen 判断，价格响应改用固定规则 | 23.59 | 21.25 |
| 只用固定价格规则，同价时三项等概率 | 21.73 | 26.86 |

固定规则指每涨 200 本币，商品相对于「都不买」的选择赔率减半。它是人为设定的试验对照，未用真人答案估计。最后一行是看到主比较后增加的诊断，直接复算，未增加模型调用。

- **模型确实有时把涨价答反了。** 单独提高一款价格的 64 次比较中，有 19 次这款的预测选择率上升。此处只检查模型对人工构造题面的反应，人工构造题面没有真人答案。
- **限制方向有效，但起点太差。** 把反向响应归零后，美加误差分别降低 6.95 和 14.47 个百分点，按卡片配对重抽样的 95% 区间分别为 1.50 至 14.05、4.34 至 26.97。修正后的两地误差仍高于直接问 Qwen。
- **固定规则比让 Qwen 自己估涨价幅度更稳。** 固定规则加 Qwen 同价判断，比直接问 Qwen 的点估计好 0.65 和 1.25 个百分点，区间分别为 −8.15 至 10.90、−6.43 至 8.61。进一步与只看价格比较，美国略差、加拿大略好，两地的区间也都跨零。

区间来自每个国家 2,000 次卡片配对重抽样，反映所选商品卡的波动。真人样本和模型调用结果在重抽样时固定。

## 下一步

保留价格方向检查，暂缓把这套价格修正用于正式预测。后续商品实验可同时放入「直接问模型」和「只看价格」两条对照，优先检查模型能否在价格相同或接近时更好地判断商品属性和拒买。每 200 本币减半的幅度只用于这次试验。

可复算材料见[汇总结果](../data/dryer-own-price-v1.json)与[执行和评分脚本](../src/dryer_price_replication.py)。使用本地检查点可运行 `.venv/bin/python examples/decision-transfer/src/dryer_price_replication.py score` 重算。
