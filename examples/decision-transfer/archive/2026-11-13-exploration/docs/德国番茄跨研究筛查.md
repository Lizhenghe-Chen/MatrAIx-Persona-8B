# 瑞士商品取舍能否用于德国番茄包装？

2026-11-13。采用瑞士电子产品来源模型已冻结的系数。德国数据来自独立调查，曾进入项目历史筛查，因此这一轮属于跨研究探索。原问卷有12张固定卡，每张三款包装加「都不买」。仅取未收到额外生物塑料说明的401人，共4,812次选择。[Findrik 与 Meixner 原始材料](https://zenodo.org/records/21740286)

按原问卷PDF重建德语选项、顺序、250克樱桃番茄、包装价格和额外保鲜天数。旧适配写成1公斤且未明确包装单独收费，本轮未沿用。原始SPSS与问卷核验作者公布的文件校验值，工作簿与README同时留作资料。原件在本机私有目录。

## 买哪款

| 方法 | 对实际选了一款商品的答案计算 Brier |
|---|---:|
| 三款等概率 | 0.6667 |
| 只迁移瑞士价格系数 | 0.6396 |
| 只把可降解当作一档环保优势 | 0.5293 |
| 同时迁移价格和环保代理 | **0.5104** |
| Qwen 直接预测 | 0.5679 |
| Qwen 加瑞士研究提示 | 0.5690 |
| 德国同卡其他人实际比例 | 0.4366 |

实际购买时，先把Qwen三款商品概率重新归一，再与统计模型在同样的人和题上比较。每个人先平均其购买题，再在受访者间平均。统计方法将0.15欧元包装价差映射为一个价格档，把可降解标签暂当一档生命周期影响优势。两项是本轮选择的映射假设，分别用单属性对照诊断。不同标签的真实环保影响并未验证。该简单模型还忽略包装材料和保鲜天数。

联合模型比Qwen直接预测改善0.0575，95%区间[0.0485, 0.0663]，约10.1%。它比只用可降解标签改善0.0190，区间[0.0147, 0.0238]。区间固定12张卡和预测，仅按人重抽样，不衡量跨商品卡或跨研究不确定性。德国同卡比例每次排除被预测者，其余同卡答案仍用于计算，因此代表已经有目标问卷数据的条件。

## 买不买

24次Qwen请求全部有效。每张卡对两种提示各询问一次，整个群体共用该卡概率，未进行逐人画像预测。真人拒买率6.05%，Qwen直接预测11.67%，加瑞士来源提示后13.42%。完整四选项Brier分别0.6386和0.6318，拒买比例却离真人更远。瑞士问卷强制购买，来源统计模型只输出购买后的相对商品选择概率。不能给它补一个未经估计的拒买率后声称完整问卷改善。

## 采用范围

此次证据支持将旧研究中可解释的商品取舍作为新品类的候选统计参照。在原属性一致的瑞士数据和德国包装压力测试中都有正面信号。德国的映射依赖两个具体假设，且只检验实际选择某款的人，尚不足以把方案推到完整购买预测。把来源系数写进Qwen提示也没有改善条件选择误差。当前没有支持用Pro复验这段提示的证据。后续应在可比研究中验证属性映射，并单独为拒买建立可迁移参照。
