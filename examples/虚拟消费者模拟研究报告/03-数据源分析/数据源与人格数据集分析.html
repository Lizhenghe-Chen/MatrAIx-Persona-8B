1这个数据集是什么

MatrAIx 是一个「先模拟、后现实」的群体级人格基础设施：把采样出的人格记录实例化为 LLM 智能体，在四类环境（Survey 问卷 / AI Chatbot 对话 / Web 网页 / App 桌面与移动应用）里跑可复现任务。Persona 1M 就是这套系统的基础数据资产。

设计定位：每个「人」被拆成 1,290 个分类维度（年龄、地区、职业、技能、价值观、大五人格、兴趣……），每个维度取一个离散值。人格 = 这些维度值的组合。它服务于用户研究、产品评估、市场模拟等场景——不能替代真实人群证据。

4数据结构：怎么存储与读取

数据以 Zstandard 压缩的 Parquet 分片存储，10 个分片（9×100,000 + 1×99,847 行）。属性经过比特级打包：每人的 1,290 个属性压缩成 645 字节（每个维度 4-bit 编码，最多 16 个取值）。

Parquet 12 列

source数据来源（wiki / stackoverflow / amazon / gss / prism / real_human_survey / synthetic）
source_row_index在来源中的原始行号
source_record_id来源记录 ID（可回溯到上游）
attributes645 字节 4-bit 打包的 1,290 个属性编码（核心负载）
null_bitmap缺失位图：置位=该维度缺失（稀疏行）
attribute_overrides超出码本范围的精确取值（覆盖编码）
has_description / description_count / descriptions字段级自然语言描述（42.26% 的行有）
grounding逐字段证据、置信度、赋值类型（可追溯）
metadata_json来源特定元数据
populated_attribute_count该行实际填充的属性数（平均 656/1290）

配套索引（快速筛选）

不用扫 4GB 也能按属性找人：indexes/postings.sqlite（2.6 GB）把每个「维度=取值」映射到全局行号。

postings 条目数10,617 个 (维度, 取值) → 行号倒排
字段数1,291（1,290 维度 + 1）
样例查询age_bracket='25-34' → 直接拿到所有行 ID
schemapostings(field_id, value, row_ids BLOB, count)

官方解码示例（pyarrow）

import json, pyarrow.parquet as pq
schema = json.load(open("persona_codes.schema.json"))["columns"]
t = pq.read_table("data/persona-1m-0000.parquet")

def decode(attributes, null_bitmap):
    out = {}
    for i, col in enumerate(schema):
        if null_bitmap and (null_bitmap[i//8] >> (i%8)) & 1:
            continue                        # 置位 = 缺失
        code = (attributes[i//2] & 0x0F) if i%2==0 else (attributes[i//2] >> 4)
        if code < len(col["values"]):
            out[col["id"]] = col["values"][code]
    return out

地区维度的坑：North America 目标 4.8%，实得 18.8%（差 14 个百分点）——因为维基百科词条天然偏向欧美人物。做地区相关分析时务必按已知人口结构加权，或使用 cohort 抽样按目标分布重采样。

9怎么用：三种打开方式

① 解码读取（官方推荐）

person = decode(t["attributes"][1].as_py(),
                t["null_bitmap"][1].as_py())
person.get("age_bracket")
# -> "45-54"   （用 .get 不用 []，行是稀疏的）

② 索引快速筛选

# 找所有「25-34 岁」的人，不用扫 4GB
SELECT value, count FROM postings
WHERE field_id = 'age_bracket';

③ 采样运行（本 demo 用法）

python scripts/generate_water_bottle_job.py \
  1000 20 survey-water-bottle-choice-v2-n1000
# 从数据集采样 1000 人格 →
# 实例化为 LLM 智能体（DeepSeek）→ 跑问卷任务

抽样会输出 YAML 人格文件（含 dimensions + provenance），并按校准目标做分层采样；本仓库 cohorts/ 目录即抽样结果。

本 demo 的经验：用 999,847 人数据集采样出 1,000 人格做「保温杯选购」问卷，成本 ¥4.5 / 34 分钟（20 并发），报告里所有分群（地区/性别/人生阶段/收入）都来自这些人格属性。

10边界与合规：必须知道的限制

许可红线（研究专用）：数据集仅限非商业研究用途，任何商用、付费托管服务均不允许；子集（包括 40 万合成人格）不因提取而获得新的许可。上游来源许可各自适用（维基 CC BY-SA 4.0、SO 问卷 ODbL、Amazon 研究用途、PRISM CC BY / CC BY-NC 等）。
官方明示的限制含义
不是任何人群的代表性样本校准只对齐一维边际，不保证联合分布；来源选择偏差仍在
「人类接地」≠「已核验」维基/Amazon/SO/PRISM 属性是模型抽取的，可能有抽取错误；描述是模型生成的
60/40 人机比例是设计选择不代表真实世界的人机比例
未成年记录已移除原 508 条真人问卷中 153 条 <18 岁被剔除，故总数是 999,847 而非 1,000,000

责任使用（论文 Appendix N）：不得冒充真实个人、不得把数据归因到可识别的人、不得尝试再识别、不得针对个人或受保护群体。官方数据卡版本化 + 文件哈希，删除记录会留档。论文：arXiv:2608.04205
