# 虚拟消费者模拟研究报告集

本目录汇总基于 MatrAIx-Persona-1M 人格数据集 × DeepSeek API 的「虚拟消费者购物式选择」模拟报告，共 3 个品类专题。

## 目录结构

| 目录 | 内容 | 建议打开顺序 |
|---|---|---|
| `01-马桶刷品类/` | 1000 位北美虚拟消费者对 10 款在售马桶刷的选择模拟：报告 + 交互数据看板 + 商品图 | 先看报告 |
| `02-保温杯品类/` | 1000 位虚拟消费者对 6 款保温杯的选择模拟：报告 + 交互数据看板 + 商品图 | 先看报告 |
| `03-数据源分析/` | MatrAIx-Persona-1M 数据集构成与字段说明（约 100 万人格、1290 维度、7 个数据源） | 理解数据基础时看 |

## 使用说明

- **模拟报告**：完整汇报页面，含核心结论、市场份额、价格带、分群画像、购买理由、业务启示，浏览器直接打开。
- **数据看板**：交互式图表（ECharts），可悬停/筛选查看明细。
- 各品类报告依赖同目录 `assets/` 商品图，转发时请连同文件夹一起发送。
- 原始明细数据（1000 行/品类，含每题答案与购买理由）存放于项目仓库 `results/` 目录，可另行索取。
