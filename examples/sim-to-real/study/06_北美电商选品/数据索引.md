# 北美电商选品数据与复算

| 文件 | 来源或内容 |
|---|---|
| [origin.csv](数据/origin.csv) | [Bankert 公开逐人选择表](https://itemresponsewarehouse.org/tables/bankert_2023_consumer_origin/) |
| [origin-original.tab](数据/origin-original.tab) | [作者复算库](https://doi.org/10.7910/DVN/3TGWGG) 的原始分析数据，含第一波测得的文化态度综合分 |
| [origin-appendix.docx](数据/origin-appendix.docx) | Cambridge 论文官方补充材料，包含量表和问卷说明 |
| [packaging.csv](数据/packaging.csv) | [Purdue 公开逐人选择表](https://itemresponsewarehouse.org/tables/staples_2020_beer_eco_labels/)，原作者数据见 DOI 10.17632/4z748jnnjs.2 |
| [pew.zip](数据/pew.zip) | [Pew Wave 111 官方数据包](https://www.pewresearch.org/internet/dataset/american-trends-panel-wave-111/)，含 SPSS 和问卷，来自用户提供的官方下载 |
| [固定方案](固定方案.md) | 预检调整、样本、提示、评分和验收 |
| [manifest.json](manifest.json) | 数据哈希、样本分层数、请求输入哈希及模型配置 |
| [sample-index.json](sample-index.json) | 正式、试跑、训练的伪编号。供本地复算 |
| [checkpoints.sqlite](checkpoints.sqlite) | 断点、答卷与失败重试记录。供本地复算 |

代码在 MatrAIx-Persona-8B 仓库的 `examples/sim-to-real/shopping.py`。使用仓库 Python 环境及 pyreadstat 1.3.7，依次运行 `shopping.py prepare|pilot|formal|score <本目录>`。复算只需 `score`。结果 HTML 只内嵌聚合数据，原始调查文件和答卷归档单独管理。
