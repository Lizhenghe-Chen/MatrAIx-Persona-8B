# 实验二　提示与背景

每份调查四个年龄学历层各抽 60 名受访者，三份共 720 人。SHED 再抽独立调试集 48 人，每层 12 人。调试仅检查输入、映射和答案格式。所有真人背景请求只发到内网 Qwen。每人的各组题序一致。目标答案、原始受访者编号和调查权重留在本地评分侧。

| 因素 | 设置 |
|---|---|
| P0 | 沿用首轮扮演一名美国成年人的提示 |
| P1 | 预测这位具体受访者当时最可能选的选项，使用提供的信息，缺失时避免编造经历 |
| B1 | 18–64 或 65+，本科以下或本科及以上 |
| B2 | Pew 用原始年龄段，SHED 和 ANES 用公开年龄字段，保留原有年龄封顶规则。学历用各调查公开的更细分档 |
| B3 | B2 加各调查的贴题变量，见下表 |
| B4 | B3 加同层无放回随机配对的四项 DAG 人格。P0 和 P1 共用配对。这些属性是合成值 |

| 调查 | B3 字段 |
|---|---|
| SHED | `ppinc7`、`ppemploy`、`pphhsize`、`ppkid017`、`I9`，收入稳定性结合 `I9_iflag` 排除插补 |
| Pew | `F_INTFREQ`、`ONLTSK_a_W168`、`ONLTSK_b_W168`、`SNSUSE_W168` |
| ANES | `V241566x`、`V241227x`、`V241177`，收入编码再归并为五档 |

计划 384 份技术试跑和 5,760 份正式答卷。对照提示词和三次背景增量，并与用评估样本外真人数据按粗年龄、学历查比例的基线比较。该基线使用同调查的历史微数据，代表可以获取同题历史数据时的统计参照。ANES 沿用首轮 `V240102a` 正权重样本，共 2,063 条，年龄学历有效后为 1,927 条。

综合误差至少下降 2 个百分点、配对 95% 区间在 0 上方、至少两份调查有正增益且没有任何一份的区间完全落在 0 以下，才标记为达到预设门槛。
