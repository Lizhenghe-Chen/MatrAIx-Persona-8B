# 公开数据的来源与许可

这些文件是研究作者或统计机构已经公开的数据和问卷；本项目产生的真人样本编号、逐人预测及关联文件另存本机，不加入 Git。核验日期为 2026-11-10。`本机数据/` 是原来的工作路径，为保证冻结方案和脚本继续可用而保留名称；其中的小型公开资料现已随 Git 保存。
