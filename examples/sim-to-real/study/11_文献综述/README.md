# 对应用户画像的决策与选择：文献综述

只读[综述正文](综述.md)即可了解研究目标、关键证据、主要实验和验收方案；核心是对应用户的决策预测，语言自然度为辅助。需要核对时再查看：

- [本地全文资料库](全文资料/全文索引.md)：21项研究已取得正文，另2项待获取；中文主题导航、版本、原文入口和文件校验。
- [文献证据卡](文献证据卡.md)：23项研究的来源、版本、核验范围与局限。
- [详细参数附录](参数与实验建议.md)：保存论文实际设置；主要实验设计已并入主文。
- [检索与更新记录](检索与更新记录.md)：检索路线、重要修正、待核验事项。
- [sources.json](sources.json)：可持续补充的结构化文献记录。

正文使用Markdown手工维护。运行`python build.py`只更新证据卡、全文索引与旧HTML入口，不覆盖正文。不要把外部论文结果记为本项目已跑出的成绩。

全文 PDF 保留原始内容。允许再分发的文件随 Git；限制用途或许可未确认的文件保存在 `全文资料/本机全文/`，由 Git 忽略。第三方论文不因本项目的代码许可而改变许可。

运行 `python manage_fulltexts.py verify` 检查文件哈希；在另一台电脑运行 `python manage_fulltexts.py download`，按固定下载地址补齐缺失文件。遇到验证或版本内容变化时停止该文件的导入，不绕过登录，也不覆盖旧版本。
