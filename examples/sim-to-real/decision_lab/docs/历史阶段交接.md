## 一句话结论

两项研究里，大语言模型都没有超过使用同样信息的统计模型：烘干机差 16.6%，瑞士家电差 45.1%（相对 Brier）。补充真实背景没有可确认的改善；错配背景也不更差。开发阶段选出的校准方案优于纯 AI，但没有超过同背景统计模型——瑞士的 AI 权重为 0，两条路线在数学上完全相同。

## 核心数字

正式测试集，Brier 越小越好：

| 做法 | 烘干机（292 人） | 瑞士家电（683 人） |
|---|---:|---:|
| AI，不加背景 | 0.6194 | 0.4088 |
| AI，加基础背景 | 0.6204 | 0.4280 |
| AI，加贴题真实背景 | 0.6097 | 0.4353 |
| 统计模型，只用商品与情境 | 0.5234 | 0.2911 |
| 统计模型，加同背景 | 0.5227 | 0.3000 |
| 开发选定方案（校准混合） | 0.5250 | 0.3000 |

主对照：纯 AI → 同背景统计模型，烘干机 −16.6%（区间全负）、瑞士 −45.1%（区间全负）；开发选定方案 → 同背景统计模型，烘干机 −0.4%（区间跨 0）、瑞士 0.0%。

## 仍然没有做的事

1. **跨题相关性与逻辑冲突的完整分析没有实现。** 每题独立调用，不能声称还原了真人整份答卷的联合分布。只做了整份答案重复度这类描述性诊断。
2. **合成人群的卡片级区间只在烘干机的主对照上成立**，且该主对照因重抽样丢失覆盖而未给出区间（4/2,000 次）。瑞士商品组合太稀疏，只作描述。
3. **其他研究尚未准入**：中国与日本有机蔬菜、德国番茄包装、美国 T 恤、RADIANT 的题面或用途边界材料不足，见[首批研究准入决定](../docs/首批研究准入决定.md)。
4. **广泛跨研究验证不存在**：两项都是耐用家电，四个国家与三类家电各自属于一项研究。

## 如何复算

评分只读本机检查点，不调用模型、不产生费用：

```sh
export PYTHONPATH=examples/sim-to-real
D=/Users/bunnychen/.local/share/matraix-decision-lab
PY=.venv/bin/python

$PY -m decision_lab.evaluation.execution_snapshot $D/dryer-text-v1 --output /tmp/dryer-verify.json
$PY -m decision_lab.evaluation.evaluate_study $D/dryer-text-v1 --kind dryer \
    --calibration $D/dryer-text-v1/calibration-v1.json --output /tmp/individual-dryer.json
$PY -m decision_lab.evaluation.evaluate_population $D/dryer-text-v1 --kind dryer --output /tmp/population-dryer.json
$PY -m decision_lab.reporting.study_report /tmp/individual-dryer.json --max-cards 120 --output /tmp/individual-dryer.html
```

瑞士家电把 `dryer` 换成 `swiss`。总报告用 `python -m decision_lab.reporting.aggregate_report`，参数见 [README](../README.md)。

**不要重新运行 `prepare`**：那会覆盖已冻结的划分、画像与配置。已有检查点中的完成记录会被自动跳过，重复调用不会发生。

## 交接与保存习惯

公开配置、汇总、代码与文档随 Git；原始真人记录、逐人关联、完整请求答卷、受限全文与凭据留本机或共享盘。私有材料可用 `python -m decision_lab.ops.handoff_manifest <目录> --output <清单>` 生成哈希清单并 `--check` 校验漂移。不要把私有目录整体加入 Git，也不要删除旧实验来掩盖失败。

用户偏好中文、通俗解释、开头结尾有结论、每个术语随手可懂，并用真实分布与图表说明“之前怎样、改了什么、之后怎样”。不把程序测试通过当成科学有效性，也不要频繁汇报微小代码进度。
