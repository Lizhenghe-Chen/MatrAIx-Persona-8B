## 写文档的规矩

1. **一份事实只有一个出处**：数字在 `reports/cross-study-v1/*.json`，台账引用它，不要在文档里另抄一份。
2. **失败也留档**：未通过门槛的尝试写进迭代日志，不删。
3. **命名区分用途**：`预注册协议-*` 是冻结标准，`阶段记录-*` 是某日事实，`*日志` 是逐轮过程。
4. **不复用文件名**：新一轮记录另立新文件，避免"同一份文档被反复改写、旧结论消失"。
