# 决策模拟通用框架

**当前状态：两套家电正式研究和两次选择探索筛查均已完成。没有正在等待的正式调用。**

先看 [全部实验的通俗总报告](../reports/index.html)，再按需要查看 [两套家电图解](reports/reader.html)、[最新两次选择筛查](reports/choice-history.html) 或 [交接状态](交接先读.md)。

## 当前证据

- 45,216 次正式调用完成，真人预测与合成人群分轨。两项家电研究中，Pro 的纯 AI 预测没有超过使用相同商品背景字段、另用真人训练答案的统计方法。
- 开发阶段选择的校准或混合没有明确超过同背景统计模型；瑞士家电的 AI 权重为 0，等同于统计方法。
- 最新探索各 48 人，修正版 600 次调用全部完成。“加本人两次选择”没有通过继续门槛；旧版 419 次在效果评分前作废，独立留档。
- 这些结果没有证明合成人格普遍有效。技术核验通过与科学效果通过是两件事。

## 文件按职责分区

| 目录 | 用途 |
|---|---|
| `core/` | 输入契约、字段白名单、模型服务适配、检查点、预算与运行器、统计参照及校准 |
| `studies/` | 数据适配、题面还原、来源审查、研究专属准备与运行 |
| `evaluation/` | 概率评分、配对区间、分群、稳定性与已知选择筛查 |
| `reporting/` | 个体、群体、逐卡和叙事报告生成 |
| `ops/` | 请求核验、恢复、交接清单与技术试跑 |
| `specs/` | `formal` 正式冻结、`pilots` 试跑、`freezes` 选参和核验、`audits` 准入审查 |
| `reports/` | 公开聚合结果与离线 HTML；不放私有完整记录 |
| `docs/` | 当前结论、复算指南、数据审查与明确标为历史的实施沿革 |
| `tests/` | 不联网的框架验证 |

新文件按职责归位；不要重新把专属脚本堆到模块根目录。核心接口不绑定某一数据集，模型调用参数通过冻结配置提供。

## 安全复算与重建

[复算与复用指南](docs/复算与复用指南.md)提供完整命令，区分“看报告”“从答卷评分”“重新调用模型”。前两项不产生 API 费用。

```sh
# 从仓库根目录，仅核验最新筛查的已完成记录
PYTHONPATH=examples/sim-to-real .venv/bin/python -m decision_lab.evaluation.choice_history --check

# 仅重建跨实验报告
.venv/bin/python examples/sim-to-real/reports/build.py
```

通用框架提供 `check / freeze / run / score / report / verify` 六类入口，研究级运行使用专属适配器。具体说明见复算指南；不要为了查看结果重新执行 `prepare`，也不要对已使用过的测试集继续挑提示。

公开汇总随 Git；冻结输入、真人关联和检查点留 `~/.local/share/matraix-decision-lab/`。在持有私有输入和完整检查点的环境中，才可重新计算逐人分数。
