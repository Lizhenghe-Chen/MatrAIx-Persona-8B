# 跨研究适用性验证：实现状态

入口：**正式结果见[六套研究正式报告](../reports/cross-study-v1/formal-report.html)**；准备过程见[开跑准备报告](../reports/cross-study-v1/index.html)。

## 正式运行已完成（2026-11-12）

六套已准入研究（美国公共支出、诈骗风险、消费调整、购物看法、四国烘干机、瑞士家电）各 96 人（烘干机 94 人，2 人无完整画像、事前排除），四组对照共 2,296 次调用，全部完成，无待处理请求。

- 冻结：`../specs/cross-study-v1/formal-v1.json`（请求哈希、人数、费用上限、评分预案）。
- 结果：`../reports/cross-study-v1/formal-results.json`（逐组数字与匹配区间）。
- 报告：`../reports/cross-study-v1/formal-report.html`（离线、可单独拷贝）。

结果要点：

1. 优化组合（预测提示＋概率）相对原生流程在六套全部显著更好，Brier 相对改善 +22.1% 至 +43.3%。
2. 但收益几乎全部来自“交出概率”，不是改提示：`原生→概率` 与 `原生→优化` 几乎相同。
3. 与统计参照相比没有任何一套胜出：四套题卡重复的研究差 8%–24%（区间全负），两套家电差 15.7% 与 27.1%（属性回归参照）。
4. 只有两套（购物看法、诈骗风险）同时达到 Brier 与“分布误差 ≥2 个百分点”双门槛；跨研究门槛（≥3 套、≥2 类任务、≥2 地区）未满足。
5. 烘干机与瑞士家电的题卡几乎人人不同，分布误差按要求不估计，不拿稀疏卡片硬算。

## 已实现并实际运行

- `audit.py`：19套原件的文件存在性、SHA-256、结构检查；冻结当前原生问卷路径。文件可读与任务准入分别记录。
- `personas.py`：10个发行分片逐字节校验；解码999,847条记录的来源与人口字段。原始画像不进入公开报告。
- `targets.py`：把六套已审查历史研究转成仅本机保存的整份问卷结构。真人背景与答案保留评分侧。
- `matching.py` / `cohort.py`：明确可比字段，按固定种子预选试跑、筛查、留出人群；画像候选与来源隔离。当前结果是候选，不是正式冻结。
- `protocol.py`：原生人格模板与问卷指令；四组保持相同画像和题面，仅改变指令与输出结构。规范值白名单、严格答案检查，不填默认答案。
- `technical.py`：4次完全虚构问卷检查。
- `prepare_pilot.py` / `run_pilot.py`：六套各1人×四组，24次整份问卷格式检查；交错运行、检查点续跑、模型身份检查。没有效果评分。
- `drone_audit.py`：重建作者配送题编码；检验重复字段、选择数量、取值及缺失教育字段。
- `report.py`：生成离线准备报告及19套准入进度表；不虚构效果图。

## 数据与运行边界

- 公共汇总：`../reports/cross-study-v1/`；方案/原生代码快照：`../specs/cross-study-v1/`。
- 私有逐人材料：`~/.local/share/matraix-decision-lab/cross-study-v1/`；权限仅本用户。密钥只读本机配置，不进入源文件或报告。
- `cohort-candidate-v1.json`保留初始映射错误审计；`v2`已修复加拿大和爱尔兰缩写。两者均未用于正式效果推断。
- 记录`source`是发行版来源标签，不是“真人实测”证明。匹配人口字段也不证明人格属性对应真人。
- 当前试跑不改变旧报告、不删除旧数据，也不能用作新方法的独立成功证据。
- 报告使用“原生提示参照”：与生产路径的差异是删除身份、只发规范字段、统一严格失败处理、适配原题结构；不能称逐字节复刻完整生产系统。
